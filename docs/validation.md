## 重现

```powershell
npm ci
npm test
npm install --no-save playwright
npx playwright install chromium
npm run test:browser -- --serve
```

浏览器脚本自动启动本地预览；执行前停止已有4173端口服务。截图保存到artifacts。CHROMIUM_EXECUTABLE_PATH为可选浏览器路径，不需要用户设置。
