# 首关美术样本与落地规格 v0.3

本轮制作三项独立美术素材：完整守卫、完整灯灵、无角色的浮空岛平台。使用内置图像生成，以已确认的首关效果稿作为风格参考。它们是 PNG 位图，不是可编辑矢量角色，也不是 Photoshop/Spine 分层源文件。

## 展示与逻辑边界

UI 的标题、护盾、次数、按钮和结算文字继续是原生可编辑组件，不能烘焙进场景图片。完整角色立绘先支持轻微浮动、位移、缩放和亮度反馈；这些不等于骨骼动画。角色动作复杂后才制作手臂、躯干、炉心、眼睛等分件，以及一致的遮挡补全。不能直接把完整立绘裁开就宣称已完成动画拆件。

本次接入浏览器按钮样机和普通微信小程序的 image 图层；Cocos 工程与真机仍待验证。效果稿中的远景城堡、植物密度和角色动作不在此次样本交付范围。

## 画布与布局

设计基准为393×852逻辑像素，场景393×340。微信布局使用750rpx参考宽度，缩放系数750/393。场景各层保持原始宽高比；不要裁去角色脚或平台底部，不要把图拉伸到固定比例。

| 层 | 绘制顺序 | 参考位置与范围 | 用途 |
|---|---:|---|---|
| 天空底色 | 0 | 填满场景 | UI底色/程序绘制 |
| 浮空岛 | 1 | 左24，上115，宽345，高230 | 独立透明PNG，contain |
| 守卫 | 2 | 左116，上28，宽168，高202 | 独立透明PNG，contain |
| 灯灵 | 3 | 左246，上37，宽74，高86 | 独立透明PNG，contain |
| 动态反馈 | 4 | 由目标锚点定位 | 伤害数字、粒子、技能反馈 |
| HUD | 5 | 场景外或安全区内 | 真实文字、护盾、暂停按钮 |

表中框为容纳范围，透明画布有留边；可视物体的精确落脚点需要在真实渲染后校准，不能只用文件尺寸判定。

配色：背景 #EDF6F0、正文 #174B46、主按钮 #267B64、微光 #F6BF64。按钮最小高度48逻辑像素；运动识别版后续增加远距离大字和免触屏操作，不沿用按钮版的操作要求。

## 五种状态

准备：展示岛屿、角色、档案选择与开始按钮。
战斗：保持角色素材身份一致，动作数字和护盾由真实状态驱动；攻击反馈只在动作保存成功后播放。
休息：场景暗化，显示已保存进度与继续/结束本轮。
阶段完成：阶段星标点亮，手动进入下一阶段；不自动倒计时推进。
通关：使用同一角色与岛屿素材增加暖光和少量粒子，真实每轮数据独立排版。

这五种状态已在浏览器和小程序界面代码中实现，页面按真实规则状态切换。浏览器已操作验证，小程序需开发者工具和真机验证。

## 导出与接入

源图片原样保留于source-assets。运行图片通过ImageMagick等比缩放导出，PNG带alpha，不做自动裁边、抠图或颜色重绘。缩放命令见tools/export-assets.sh；无需重新生成图像。实际尺寸、可见边界、磁盘体积与RGBA解码内存见 assets.json。PNG压缩体积不等于运行时内存；解码成本按宽×高×4估算，多份纹理会重复占用内存。

目录 `preview/assets` 用于浏览器；`miniprogram/assets` 为同名本地素材。当前两份副本是独立平台入口，尚未做构建阶段自动同步。后续Cocos以同样文件作为Sprite素材导入，并按照实际透明留边设置锚点；必须在Cocos编辑器核对纹理设置、加载、缩放和批次。

`scene-layout.svg` 为独立的可编辑场景组合稿：三层图像可分别移动缩放，天空是矢量背景。它不是插画分层源文件；位图内部无法在SVG编辑器中改成机械部件。

仍需人工/真机确认：画风一致性、PNG边缘、角色落脚位置、小尺寸清晰度、微信包体与解码内存、实际手机布局、攻击效果、五态完整UI、Cocos导入。

## 本轮检查结果

PNG有透明通道；运行导出总计约0.73MB、RGBA约2.75MiB。全部五种状态已在实际浏览器中操作并截图检查；截图见screens。微信与Cocos尚未验证。

阶段完成与通关使用同一套角色、独立星光、暖色背景，不冒充角色动作变体。攻击为短位移和伤害数字；灯灵为浮动。未实现音效、骨骼动画、远景建筑、训练识别。浏览器支持系统减少动态效果偏好；微信动态效果的设置入口待补充。
